# v0.4.0 — Rust release preview & audit resolution

Version 0.4.0 represents the unified Rust rewrite and resolves the findings
identified during the local migration audit.

## Key Changes in 0.4.0

- **Release Identity:** Bumped version to 0.4.0 across Cargo manifest and metadata.
- **Reverse Focus Navigation (`Shift+F6`):** Handled globally in event dispatch,
  cycling backwards through visible workspace regions (`Editor` → `VerticalTerminal` →
  `Drawer` → `Sidebar` → `Editor`).
- **Keyboard Panel Resizing (`Alt+Arrow`):** `Alt+Left`/`Alt+Right` adjusts the
  vertical terminal divider (if focused or sidebar is collapsed) or sidebar divider;
  `Alt+Up`/`Alt+Down` adjusts the drawer divider. Visible Zen panes can resize with
  safe bounds clamping.
- **Hardcoded Aliases Removed:** Removed hardcoded `<C-b>` and `<F6>` aliases in
  `events.rs`, ensuring user rebindings in `settings.json` take full effect.
- **Real Opt-In Vim-Safe Preset:** Retains Ctrl-based factory defaults (`Ctrl+E`,
  `Ctrl+T`, `Ctrl+N`, `Ctrl+P`, `Ctrl+S`, `Ctrl+Q`), while offering an opt-in
  Vim-safe preset (`v` in Settings tab 4) using `Alt+E`, `Alt+T`, `Alt+N`,
  `Alt+P`, `Alt+Q`, and `F2` to free Vim motion and completion keys. Existing
  saved settings take precedence.
- **Bug Reporting Action (`F12`):** Defaults `report_bug` to `F12`. Saved empty
  bindings are preserved.
- **Window Split & AI Shortcut Disambiguation:** Restored `<M-s>` for `:split`
  and `<M-c>` for `:close`. AI assistant context actions use `Ctrl+Alt+S`/`F`/`C`
  or leader chords (`Space a s/f/c`).
- **Native Explorer via `Space e`:** In Normal mode, `<leader>e` calls
  `tuim_toggle_explorer` over RPC, toggling the native Workspace Explorer without
  depending on external plugins.
- **Git Staging Shortcuts:** Added `+` (stage) and `-` (unstage) alongside `Space`
  and `s` (toggle).
- **Bug Report Lifecycle & Redaction:** Replaced prefix-restart loop in `redact_text`
  with cursor-based scanning. Report submission runs `curl` directly as a tracked
  child process without shell interpolation, cleaning up temporary files and
  reaping in-flight processes on drop.
- **Selective Uninstaller Scope:** In `uninstall.sh`, `--plugins` removes installed
  plugin assets while preserving user plugin configs (`plugin_configs/`) and
  preferences. `--settings` removes configuration and `settings.json`. `--all`
  removes all Tuim directories.
