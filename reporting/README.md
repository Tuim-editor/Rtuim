# TUIM bug-report gateway

This Cloudflare Worker receives the in-app report and creates an issue through
a GitHub App. GitHub credentials remain in encrypted Worker secrets; TUIM and
its users never receive or handle them.

## One-time GitHub setup

1. Create a GitHub App owned by the repository owner.
2. Give it **Issues: Read and write** and **Metadata: Read-only** repository
   permissions. It needs no user permissions or webhook.
3. Install it only on `Tuim-editor/Rtuim` and record the App and installation IDs.
4. Generate and download a private key. Keep it outside this repository.

GitHub installation tokens are short-lived and are generated by the Worker for
the single configured repository.

## Deploy

```sh
cd reporting
npm install
npx wrangler login
npx wrangler kv namespace create REPORT_LIMITS
```

Put the returned namespace ID in `wrangler.toml`, then configure secrets. Run
these commands yourself; do not paste their values into source files or chat:

```sh
npx wrangler secret put GH_APP_ID
npx wrangler secret put GH_INSTALLATION_ID
npx wrangler secret put GH_PRIVATE_KEY
npm run deploy
```

Run the Rust binary with the resulting HTTPS Worker URL:

```sh
TUIM_BUG_REPORT_URL=https://tuim-bug-report.YOUR_SUBDOMAIN.workers.dev/report ./target/release/tuim
```

The Rust widget reads `TUIM_BUG_REPORT_URL` at runtime. It defaults to
`https://tuim-bug-report.workers.dev/report`. There is no compiled endpoint
setting or release-workflow endpoint variable in the Rust build.

## Abuse and privacy controls

- Reports are limited to five per source IP per hour using Workers KV.
- Input fields and request size are strictly bounded.
- The Rust payload contains category, summary, description, and runtime diagnostics.
  It does not attach the former Zig client’s log excerpt.
- Runtime diagnostics include Tuim version, OS, architecture, mode, theme,
  terminal dimensions/capabilities and emitted bytes.
- The client attempts home-path and token redaction. Review reports before
  sending; redaction cannot guarantee that every secret is detected. Transport
  tests use local mocks; delivery to the live service still needs validation.
- The gateway does not log report bodies or source IPs.
